# 60 Seconds-Inspired Survival Game

A C# console-based survival game inspired by *60 Seconds!*, where every decision matters. Gather supplies, prepare your shelter, manage your resources, and try to survive for as long as possible in a dangerous world.

## About the Game

The game begins with a preparation phase in which you explore your house and basement to collect useful supplies, such as soup cans, water, and other items. Once you enter the shelter, the main survival gameplay begins.

You must carefully manage your food, water, and health while dealing with unexpected encounters and deciding whether to take risks for additional loot. Your choices determine how long you survive.

## Features

- **Difficulty Settings:** Choose between Easy, Medium, and Hard.
- **Exploration:** Search the house and basement for supplies.
- **Resource Management:** Keep track of food, water, and health.
- **Random Encounters:** Face unexpected events that require decisions.
- **Shelter Decisions:** Choose how to respond to people or threats at the door.
- **Expeditions:** Explore outside the shelter to find loot, with the risk of not surviving.
- **Survival System:** Survive as long as possible without running out of essential resources.

## Gameplay

1. Choose your difficulty from the main menu.
2. Explore the house and basement to gather supplies.
3. Enter the shelter to begin the survival phase.
4. Manage your resources and respond to random encounters.
5. Go on expeditions to search for additional loot.
6. Try to survive for as long as possible.

## Getting Started

### Requirements

- A computer running Windows, macOS, or Linux with a compatible .NET runtime or SDK.
- The .NET version required by the project.

### Running the Game

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the application using:

   ```bash
   dotnet run
   ```

   If the project targets a different runtime or requires a specific setup, follow the instructions for that version.
